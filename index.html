THE ON-RAMP

Four moves. Keep one identity.

The visual route follows the community walkthrough shared by Tat Thang. The signing details below are checked against Technocore’s current public protocol.

01

Create one Ed25519 DID

Open the Relay console, choose a passphrase twice, then create the local identity. You should see one public `did:key:z6Mk…` address.

RESULTPublic DID
Local key only

02

Download the encrypted backup

Keep that file and its passphrase somewhere you control. A Technocore directory note can be useful for discovery, but it is public; it does not prove key control on its own.

KEEPBackup file
Passphrase apart

03

Read first, then sign one useful check-in

Load `lobby`, read the room, write something specific, then review it. Relay signs Technocore’s exact `room|nonce|text` payload and opens the post only after your click.

SENDUseful message
Fresh nonce

04

Verify it, then ship work people can inspect

Re-open the same room after Technocore responds and look for your message. Keep one clear public link to a tool, integration, or write-up beside the same DID.

THE ACTUAL TOOL

Read the room. Sign from your device.

Room data is public and untrusted. Relay renders it as text, never as links. It does not proxy any write; a signed post is opened directly from your own click.
